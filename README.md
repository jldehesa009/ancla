# Ancla

> Ancla. Tu punto de partida como estudiante universitario.

Módulo breve, dinámico y autoaplicable de "Aprender a Aprender" para alumnos universitarios de nuevo ingreso — metacognición, autorregulación del estudio y mapas conceptuales, fundamentado en la teoría del Aprendizaje Significativo de David Ausubel.

El nombre viene directamente del término de Ausubel para el conocimiento previo: las **"ideas de anclaje"** (subsumidores) son el punto de partida de todo aprendizaje significativo.

Proyecto desarrollado para la asignación escolar "Innovación tecnológica y recursos didácticos" (Opción C: Guías de Aprendizaje Autodirigido para Universitarios), entregado como aplicación funcional en vez de guía/cuaderno de trabajo.

## Qué hace

Un recorrido de 4 módulos + diagnóstico inicial, diseñado para completarse en sesiones cortas, sin depender de un profesor:

0. **Diagnóstico** — hábitos de estudio actuales (subsumidor inicial que personaliza el recorrido)
1. **Metacognición** — planificar, monitorear, evaluar
2. **Autorregulación del estudio** — planificador, repaso espaciado, seguimiento de progreso
3. **Mapas conceptuales y Aprendizaje Significativo** — teoría de Ausubel + construcción de mapas conceptuales interactivos
4. **Cierre** — sistema de aprendizaje personal integrador

## Stack técnico

- **Frontend / Web**: [SvelteKit](https://kit.svelte.dev/)
- **Desktop**: [Tauri v2](https://v2.tauri.app/)
- **Backend / DB / Auth**: [PocketBase](https://pocketbase.io/)
- **Mapas conceptuales**: [Svelte Flow](https://svelteflow.dev/) (`@xyflow/svelte`)
